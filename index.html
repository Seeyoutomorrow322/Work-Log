1차 실습 범위 시간

1차 실습 범위 시간

First Practice Scope & Timeline / 第一阶段实践范围与时间

GitHub Pages를 이용해 정적 웹사이트를 배포하고, Supabase를 연동해 업무일지 데이터를 관리합니다.

목표 / Goal / 目标

GitHub Pages + Supabase 연동으로 업무일지 작성, 저장, 조회가 가능한 기본 서비스를 완성합니다.

02

화면 구성 기준

Page Structure / 页面规范

01

화면 01 · 대시보드 (仪表盘)

전체 업무일지 수와 진행 상태를 요약하고, 최근 기록을 확인하는 첫 화면입니다.

02

화면 02 · 업무일지 목록 (日志列表)

기록을 날짜, 작성자, 주요 업무, 상태별로 확인하고 상세 내용을 엽니다.

03

화면 03 · 작성 및 편집 (编写与编辑)

기본 정보와 일일 업무 내용을 작성하고, 기존 기록을 수정합니다.

04

화면 04 · 상세 및 PDF 출력 (详情与PDF导出)

저장된 보고서를 읽기 쉬운 형식으로 확인하고 인쇄하거나 PDF로 출력합니다.

03

필수 / 향후 확장

Required / Future / 必备与后续扩展

필수 / Required / 必需

일지 작성·조회·수정, 상태 표시, 반응형 화면, 데이터 저장을 구현합니다.

향후 확장 / Future / 后续扩展

사용자 인증, 검색·필터, 기간별 통계, 관련별 접근 기능을 추가할 수 있습니다.
